0. 一分钟看懂

豆包输入法打字时用的「语音输入」，本质是客户端把麦克风音频发到字节的流式识别服务。它不需要登录、也没有对外公开 API，但它的凭据是按设备匿名下发的，所以我们可以自己复刻整条链路：

你的程序 ──①注册匿名设备──▶ log.snssdk.com 得到 device_id ──②用 device_id 换 key─▶ is.snssdk.com/settings 得到 asr_config.app_key ──③连 WebSocket────────▶ frontier-audio-ime-ws.doubao.com │ StartTask → StartSession │ TaskRequest（16k PCM / 20ms 一帧） │ FinishSession ◀──── ④识别结果（累积文本 + 逐字时间）──────────────────┘
能不能直接用？能，实测在 Linux 服务器上跑通了中文、英文、中英混说。 但它是未公开的内部接口：凭据按设备下发、随时可能变更或加风控，请只用于技术研究与自用，别拿去做对外产品（想产品化用火山引擎官方接口或本地开源模型）。

1.3 识别协议

一条 WebSocket 长连接，二进制 protobuf 帧，四个步骤：

连接 wss://frontier-audio-ime-ws.doubao.com/ocean/api/v1/ws?aid=685343&device_id=<did> 头部 User-Agent: com.bytedance.android.doubaoime/... ← 伪装成官方客户端 proto-version: v2 ← 关键！没有它就回 JSON 而不是 protobuf x-custom-keepalive: true ① StartTask { token=app_key, service=ASR } → TaskStarted ② StartSession { payload=会话参数 JSON } → SessionStarted ③ TaskRequest ×N { audio=20ms PCM, frame_state=1/3/9 } → 结果 JSON（累积文本） ④ FinishSession → SessionFinished

1.6 豆包的离线识别是怎么做的

这是本轮最有价值的发现。结论先给：离线识别 = 字节自研端侧推理引擎 Flute + 联网下载的模型包， 而且 Windows 0.9.2.7 里还没有这套东西（Android / macOS 有）。

层证据Windows 0.9.2.7macOS 1.0.2Android 1.5.1
端侧推理引擎 Flute flute/engine/engine.cc、flute_c_api.cc、flute/framework/*、 flute/base/filesystem_mmap/filesystem_packed_mmap.cc（打包 mmap 模型容器） 无主程序内libaudioeffect.so

模型长什么样

macOS 主程序里写死了模型的张量文件名（93 个 .bin/.dat/json），可以直接读出结构 —— 是 PANTHER Conformer 编码器 + LLM 风格解码器，CIF（连续积分激发）机制，int8 量化：

s/panther_conformer_*                     编码器
s/panther_decoder_L*                      解码器
s/panther_l0_{qkv_pre_rope,mha_raw,ffn1_gemm1,ffn2_swiglu,rmsnorm1,rmsnorm2,conv_out}.bin
up_proj.bin / down_proj.bin / v_proj.bin / swiglu.bin / o_proj ...   权重张量
*_shape.dat / input_shape.dat / config.json / token_config.json / llm_params.json

算力后端是 CPU int8（源码里有 PackBS8 format: 4x4 tiled layout matching CPU prepacked weights） 加 GPU kernel（macOS 用 Metal，源码里带 device const char* 的着色器）。体量对得上"离线模型包约 150 MB"的说法。

在线 / 离线怎么协同（SAMI 里的融合策略）

  • PutOnlineCacheAudioToOffline：把在线期间缓存的音频交给整段识别重跑
  • [online vs offline] words num: [%d vs %d]：两份结果对比择优
  • 触发条件：asr has no network, switch to offline、asr has no result, switch to offline、recv interval time
  • 时间参数：finish_wait_offline_time / offline_wait_online_time / max_wait_switch_offline_time
  • 应用侧：openASRPanel canceled: network disconnected, offlineModelStatus=、Skip smart text enable prompt: reason=offline_result
为什么不能直接拿客户端里的那份用： ① 模型是私有逐张量格式（SAMI 容器，载荷加密，熵 ≈ 8.0），引擎里写死了张量名； ② Flute 静态编进客户端（macOS 主程序 / Android 的 libaudioeffect.so），Windows 包里根本没有； ③ 客户端要的模型名是加密的（name_sec），扒不出它到底用哪个。
但这不等于拿不到可用的模型——字节的算法分发接口是公开的，里面有同架构的明文 ONNX，见 1.7。

2. 凭据从哪来（为什么不用登录）

豆包输入法没有任何账号体系参与语音识别，身份是「应用身份 + 设备身份」：

① POST https://log.snssdk.com/service/2/device_register/ body: {magic_tag:"ss_app_log", header:{aid:685343, app_name:"oime", cdid/openudid/clientudid, …}} resp: {device_id, install_id, device_token} ← 匿名注册一台设备（头条系通用接口） ② POST https://is.snssdk.com/service/settings/v3/?device_id=<did>&cdid=<cdid> header: x-ss-stub = md5("body=null").upper() resp: data.settings.asr_config.app_key = "RTIHIRzbwS" ← ASR 用的 token，按设备下发 应用级 aid（编译进客户端）+ 设备级 app_key → 服务端据此计量/风控，不需要用户账号
要素值 / 说明
aid685343（取自 ImeService.exe）
User-Agentcom.bytedance.android.doubaoime/100102018 (Linux; U; Android 16; en_US; Pixel 7 Pro; Build/BP2A.250605.031.A2)
app_key按设备/时间下发（同一设备多次调用会拿到稳定的值，换设备就变），建议缓存 12 小时
为什么不需要登录身份建立在"应用 + 设备"上；这也是头条系 App 的通用做法（安装即匿名注册）
你的程序里不要暴露 app_key 给前端（它是设备级凭据），网页端一律走服务端中转。

def _varint(value):
    out = bytearray()
    while True:
        byte = value & 0x7F
        value >>= 7
        out.append(byte | 0x80 if value else byte)
        if not value:
            return bytes(out)


def encode(token="", method="", payload="", audio=b"", request_id="", state=0):
    """上游请求帧的字段号（实测得到）：
       2=token(app_key) 3=service_name 5=method 6=payload 7=audio 8=request_id 9=frame_state
    """
    body = bytearray()
    for num, val in ((2, token), (3, "ASR"), (5, method), (6, payload)):
        if val:
            raw = val.encode()
            body += _varint(num << 3 | 2) + _varint(len(raw)) + raw
    if audio:
        body += _varint(7 << 3 | 2) + _varint(len(audio)) + audio
    if request_id:
        raw = request_id.encode()
        body += _varint(8 << 3 | 2) + _varint(len(raw)) + raw
    if state:
        body += _varint(9 << 3) + _varint(state)
    return bytes(body)


def decode(data):
    """响应帧 → {字段号: [值]}。2=task_id 4=消息类型 5=状态码 6=状态文本 7=结果 JSON"""
    out, off = {}, 0

    def read_varint(buf, pos):
        val = shift = 0
        while True:
            byte = buf[pos]
            pos += 1
            val |= (byte & 0x7F) << shift
            shift += 7
            if not byte & 0x80:
                return val, pos

    while off < len(data):
        tag, off = read_varint(data, off)
        field, wire = tag >> 3, tag & 7
        if wire == 0:
            val, off = read_varint(data, off)
            out.setdefault(field, []).append(val)
        elif wire == 2:
            length, off = read_varint(data, off)
            out.setdefault(field, []).append(data[off:off + length])
            off += length
        elif wire == 1:
            off += 8
        elif wire == 5:
            off += 4
        else:
            break
    return out


def text_of(msg, field):
    val = msg.get(field)
    if not val:
        return None
    return val[0].decode("utf-8", "replace") if isinstance(val[0], bytes) else val[0]

def is_retryable(err):
    """上游会偶发 50700000 service discovery failure（实测约 1/5 概率），重试即可。"""
    msg = str(err)
    return "service discovery" in msg or any(f"[{code}" in msg for code in range(50000000, 60000000))


async def transcribe(path, retries=4):
    """带重试的一次识别：上游抖动 / 连接断开都重试整段。"""
    last_error = None
    for attempt in range(retries):
        try:
            return await _transcribe_once(path)
        except Exception as exc:                     # noqa: BLE001
            last_error = exc
            if not is_retryable(exc) or attempt == retries - 1:
                raise
            print(f"  [重试 {attempt + 1}/{retries - 1}] {exc}", file=sys.stderr)
            await asyncio.sleep(0.6)
    raise last_error


async def _transcribe_once(path):
    with wave.open(path, "rb") as wav:
        assert (wav.getnchannels(), wav.getsampwidth(), wav.getframerate()) == (1, 2, 16000), \
            "需要 16kHz / 单声道 / 16bit 的 WAV（可用 ffmpeg -ar 16000 -ac 1 转换）"
        pcm = wav.readframes(wav.getnframes())

    device_id, app_key = get_credentials()
    url = f"{WS_URL}?aid={AID}&device_id={device_id}"
    headers = {"User-Agent": UA, "proto-version": "v2", "x-custom-keepalive": "true"}
    request_id = str(uuid.uuid4())
    text, done = "", False

    async with websockets.connect(url, additional_headers=headers,
                                  open_timeout=15, max_size=None) as ws:
        # ① StartTask：建任务
        await ws.send(encode(app_key, "StartTask", request_id=request_id))
        msg = decode(await ws.recv())
        if text_of(msg, 4) != "TaskStarted":
            raise RuntimeError(f"StartTask 失败: {text_of(msg, 4)} {msg.get(5)} {text_of(msg, 6)}")

        # ② StartSession：声明音频格式 + 识别参数
        session_payload = json.dumps({
            "audio_info": {"channel": 1, "format": "raw", "sample_rate": SAMPLE_RATE},
            "enable_punctuation": True,
            "enable_speech_rejection": False,
            "extra": {
                "did": device_id, "input_mode": "tool",
                "strong_ddc": True, "use_twopass_retry": True,
                "enable_asr_twopass": True, "enable_asr_threepass": True,
                "disable_user_words": False, "cell_compress_rate": 8,
            },
        }, ensure_ascii=False)
        await ws.send(encode(app_key, "StartSession", payload=session_payload, request_id=request_id))
        msg = decode(await ws.recv())
        if text_of(msg, 4) != "SessionStarted":
            raise RuntimeError(f"StartSession 失败: {text_of(msg, 4)} {msg.get(5)} {text_of(msg, 6)}")

        # ③ TaskRequest：20ms 一帧；首帧 1、中间 3、末帧 9
        frames = [pcm[i:i + FRAME_BYTES] for i in range(0, len(pcm), FRAME_BYTES)]
        for index, frame in enumerate(frames):
            state = 1 if index == 0 else (9 if index == len(frames) - 1 else 3)
            await ws.send(encode("", "TaskRequest", payload="{}", audio=frame,
                                 request_id=request_id, state=state))
            await asyncio.sleep(0.02)          # 按实时速度喂；也可以更快

        # ④ FinishSession：收尾
        await ws.send(encode(app_key, "FinishSession", request_id=request_id))

        while not done:
            msg = decode(await asyncio.wait_for(ws.recv(), timeout=20))
            kind, result = text_of(msg, 4), text_of(msg, 7)
            if result:
                data = json.loads(result)
                for item in data.get("results") or []:
                    if item.get("text"):
                        text = item["text"]        # 累积文本，最后一条即完整结果
            if kind in ("SessionFinished", "TaskFinished"):
                done = True
            elif kind in ("SessionFailed", "TaskFailed"):
                raise RuntimeError(f"识别失败: {msg.get(5)} {text_of(msg, 6)}")
    return text

function varint(value) {
  const out = [];
  while (true) {
    let byte = value & 0x7f;
    value = Math.floor(value / 128);
    out.push(value ? byte | 0x80 : byte);
    if (!value) return Buffer.from(out);
  }
}

function encode({ token = "", method = "", payload = "", audio = null, requestId = "", state = 0 }) {
  const parts = [];
  for (const [num, val] of [[2, token], [3, "ASR"], [5, method], [6, payload]]) {
    if (!val) continue;
    const raw = Buffer.from(val, "utf8");
    parts.push(varint((num << 3) | 2), varint(raw.length), raw);
  }
  if (audio && audio.length) {
    parts.push(varint((7 << 3) | 2), varint(audio.length), audio);
  }
  if (requestId) {
    const raw = Buffer.from(requestId, "utf8");
    parts.push(varint((8 << 3) | 2), varint(raw.length), raw);
  }
  if (state) parts.push(varint(9 << 3), varint(state));
  return Buffer.concat(parts);
}

function decode(buf) {
  const out = {};
  let off = 0;
  const readVarint = (pos) => {
    let val = 0, shift = 0;
    while (true) {
      const byte = buf[pos++];
      val |= (byte & 0x7f) << shift;
      shift += 7;
      if (!(byte & 0x80)) return [val, pos];
    }
  };
  while (off < buf.length) {
    let tag; [tag, off] = readVarint(off);
    const field = tag >> 3, wire = tag & 7;
    if (wire === 0) {
      let val; [val, off] = readVarint(off);
      (out[field] ||= []).push(val);
    } else if (wire === 2) {
      let len; [len, off] = readVarint(off);
      (out[field] ||= []).push(buf.subarray(off, off + len));
      off += len;
    } else if (wire === 1) off += 8;
    else if (wire === 5) off += 4;
    else break;
  }
  return out;
}

const textOf = (msg, field) => {
  const val = msg[field]?.[0];
  return val == null ? null : (Buffer.isBuffer(val) ? val.toString("utf8") : val);
};

function readWav(path) {
  const buf = fs.readFileSync(path);
  if (buf.toString("ascii", 0, 4) !== "RIFF") throw new Error("不是 WAV 文件");
  let off = 12;
  while (off + 8 <= buf.length) {
    const id = buf.toString("ascii", off, off + 4);
    const size = buf.readUInt32LE(off + 4);
    if (id === "fmt ") {
      const channels = buf.readUInt16LE(off + 10);
      const rate = buf.readUInt32LE(off + 12);
      const bits = buf.readUInt16LE(off + 22);
      if (channels !== 1 || rate !== SAMPLE_RATE || bits !== 16) {
        throw new Error(`需要 16kHz/单声道/16bit 的 WAV，实际 ${rate}Hz/${channels}ch/${bits}bit`);
      }
    }
    if (id === "data") {
      return buf.subarray(off + 8, off + 8 + size);
    }
    off += 8 + size + (size % 2);
  }
  throw new Error("WAV 里没有 data 段");
}

async function transcribeOnce(path) {
  const pcm = readWav(path);
  const { deviceId, appKey } = await getCredentials();
  const requestId = crypto.randomUUID();
  const ws = new WebSocket(`${WS_URL}?aid=${AID}&device_id=${deviceId}`, {
    headers: { "User-Agent": UA, "proto-version": "v2", "x-custom-keepalive": "true" },
  });

  let text = "";
  let finished = false;
  let failure = null;
  const queue = [];
  const waiters = [];
  let closed = false;

  ws.on("message", (data) => {
    const msg = decode(Buffer.from(data));
    if (waiters.length) waiters.shift()(msg); else queue.push(msg);
  });
  ws.on("error", (err) => { failure = failure || err; closed = true; while (waiters.length) waiters.shift()(null); });
  ws.on("close", () => { closed = true; while (waiters.length) waiters.shift()(null); });

  const nextMessage = () => new Promise((resolve, reject) => {
    if (queue.length) return resolve(queue.shift());
    if (closed) return reject(new Error("连接已关闭"));
    const timer = setTimeout(() => reject(new Error("等待上游响应超时")), 25000);
    waiters.push((msg) => { clearTimeout(timer); msg ? resolve(msg) : reject(new Error("连接已关闭")); });
  });

  await new Promise((resolve, reject) => {
    ws.once("open", resolve);
    ws.once("error", () => reject(new Error("WebSocket 连接失败")));
  });

  // ① StartTask
  ws.send(encode({ token: appKey, method: "StartTask", requestId }));
  let msg = await nextMessage();
  if (textOf(msg, 4) !== "TaskStarted") {
    throw new Error(`StartTask 失败: ${textOf(msg, 4)} ${msg[5]} ${textOf(msg, 6)}`);
  }

  // ② StartSession
  const sessionPayload = JSON.stringify({
    audio_info: { channel: 1, format: "raw", sample_rate: SAMPLE_RATE },
    enable_punctuation: true,
    enable_speech_rejection: false,
    extra: {
      did: deviceId, input_mode: "tool",
      strong_ddc: true, use_twopass_retry: true,
      enable_asr_twopass: true, enable_asr_threepass: true,
      disable_user_words: false, cell_compress_rate: 8,
    },
  });
  ws.send(encode({ token: appKey, method: "StartSession", payload: sessionPayload, requestId }));
  msg = await nextMessage();
  if (textOf(msg, 4) !== "SessionStarted") {
    throw new Error(`StartSession 失败: ${textOf(msg, 4)} ${msg[5]} ${textOf(msg, 6)}`);
  }

  // ③ 边收结果边发音频
  const collector = (async () => {
    while (!finished) {
      let incoming;
      try {
        incoming = await nextMessage();
      } catch (err) { failure = failure || err; return; }
      if (!incoming) { failure = failure || new Error("连接提前关闭"); return; }
      const kind = textOf(incoming, 4);
      const result = textOf(incoming, 7);
      if (result) {
        const data = JSON.parse(result);
        for (const item of data.results || []) {
          if (item.text) text = item.text;        // 累积文本，最后一条即完整结果
        }
      }
      if (kind === "SessionFinished" || kind === "TaskFinished") finished = true;
      if (kind === "SessionFailed" || kind === "TaskFailed") {
        failure = new Error(`识别失败: ${incoming[5]} ${textOf(incoming, 6)}`);
        finished = true;
      }
    }
  })();

  for (let i = 0; i < pcm.length; i += FRAME_BYTES) {
    const frame = pcm.subarray(i, i + FRAME_BYTES);
    const state = i === 0 ? 1 : (i + FRAME_BYTES >= pcm.length ? 9 : 3);
    ws.send(encode({ method: "TaskRequest", payload: "{}", audio: frame, requestId, state }));
    await new Promise((r) => setTimeout(r, 20));         // 按实时速度喂
  }

  // ④ FinishSession
  ws.send(encode({ token: appKey, method: "FinishSession", requestId }));
  await Promise.race([collector, new Promise((r) => setTimeout(r, 25000))]);
  ws.close();
  if (failure) throw failure;
  return text;
}

func postJSON(endpoint string, params url.Values, body []byte, headers map[string]string, out any) error {
	req, err := http.NewRequest(http.MethodPost, endpoint+"?"+params.Encode(), bytes.NewReader(body))
	if err != nil {
		return err
	}
	for k, v := range headers {
		req.Header.Set(k, v)
	}
	resp, err := httpClient.Do(req)
	if err != nil {
		return err
	}
	defer resp.Body.Close()
	raw, _ := io.ReadAll(resp.Body)
	if resp.StatusCode != http.StatusOK {
		return fmt.Errorf("%s HTTP %s: %s", endpoint, resp.Status, string(raw))
	}
	return json.Unmarshal(raw, out)
}

// ---------------------------------------------------------------- 2. protobuf 帧

func putVarint(buf *bytes.Buffer, value uint64) {
	for {
		b := byte(value & 0x7f)
		value >>= 7
		if value != 0 {
			buf.WriteByte(b | 0x80)
		} else {
			buf.WriteByte(b)
			return
		}
	}
}

func putBytes(buf *bytes.Buffer, field int, raw []byte) {
	if len(raw) == 0 {
		return
	}
	putVarint(buf, uint64(field<<3|2))
	putVarint(buf, uint64(len(raw)))
	buf.Write(raw)
}

// encode 上游请求帧：2=token 3=service 5=method 6=payload 7=audio 8=request_id 9=frame_state
func encode(token, method, payload string, audio []byte, requestID string, state int) []byte {
	var buf bytes.Buffer
	putBytes(&buf, 2, []byte(token))
	putBytes(&buf, 3, []byte("ASR"))
	putBytes(&buf, 5, []byte(method))
	putBytes(&buf, 6, []byte(payload))
	putBytes(&buf, 7, audio)
	putBytes(&buf, 8, []byte(requestID))
	if state != 0 {
		putVarint(&buf, uint64(9<<3))
		putVarint(&buf, uint64(state))
	}
	return buf.Bytes()
}

func readVarint(data []byte, pos int) (uint64, int) {
	var value uint64
	var shift uint
	for {
		b := data[pos]
		pos++
		value |= uint64(b&0x7f) << shift
		shift += 7
		if b&0x80 == 0 {
			return value, pos
		}
	}
}

// decode 响应帧 → 字段号到值的映射（2=task_id 4=事件 5=状态码 6=状态文本 7=结果 JSON）
func decode(data []byte) map[int][][]byte {
	out := map[int][][]byte{}
	for off := 0; off < len(data); {
		tag, next := readVarint(data, off)
		off = next
		field, wire := int(tag>>3), int(tag&7)
		switch wire {
		case 0:
			val, next := readVarint(data, off)
			off = next
			raw := make([]byte, 8)
			binary.LittleEndian.PutUint64(raw, val)
			out[field] = append(out[field], raw)
		case 2:
			length, next := readVarint(data, off)
			off = next
			out[field] = append(out[field], data[off:off+int(length)])
			off += int(length)
		case 1:
			off += 8
		case 5:
			off += 4
		default:
			return out
		}
	}
	return out
}

func textOf(msg map[int][][]byte, field int) string {
	values := msg[field]
	if len(values) == 0 {
		return ""
	}
	return string(values[0])
}

func codeOf(msg map[int][][]byte) uint64 {
	values := msg[5]
	if len(values) == 0 {
		return 0
	}
	return binary.LittleEndian.Uint64(values[0])
}

func readWav(path string) ([]byte, error) {
	raw, err := os.ReadFile(path)
	if err != nil {
		return nil, err
	}
	if len(raw) < 44 || string(raw[0:4]) != "RIFF" {
		return nil, errors.New("不是 WAV 文件")
	}
	for off := 12; off+8 <= len(raw); {
		id := string(raw[off : off+4])
		size := int(binary.LittleEndian.Uint32(raw[off+4 : off+8]))
		if id == "fmt " {
			channels := binary.LittleEndian.Uint16(raw[off+10 : off+12])
			rate := binary.LittleEndian.Uint32(raw[off+12 : off+16])
			bits := binary.LittleEndian.Uint16(raw[off+22 : off+24])
			if channels != 1 || rate != sampleRate || bits != 16 {
				return nil, fmt.Errorf("需要 16kHz/单声道/16bit 的 WAV，实际 %dHz/%dch/%dbit", rate, channels, bits)
			}
		}
		if id == "data" {
			end := off + 8 + size
			if end > len(raw) {
				end = len(raw)
			}
			return raw[off+8 : end], nil
		}
		off += 8 + size + size%2
	}
	return nil, errors.New("WAV 里没有 data 段")
}

type result struct {
	Results []struct {
		Text string `json:"text"`
	} `json:"results"`
}

func transcribeOnce(path string) (string, error) {
	pcm, err := readWav(path)
	if err != nil {
		return "", err
	}
	deviceID, appKey, err := getCredentials()
	if err != nil {
		return "", err
	}
	requestID := uuid.NewString()

	header := http.Header{}
	header.Set("User-Agent", userAgent)
	header.Set("proto-version", "v2")
	header.Set("x-custom-keepalive", "true")
	target := fmt.Sprintf("%s?aid=%d&device_id=%s", wsURL, aid, deviceID)
	conn, _, err := websocket.DefaultDialer.Dial(target, header)
	if err != nil {
		return "", err
	}
	defer conn.Close()

	// ① StartTask
	if err = conn.WriteMessage(websocket.BinaryMessage, encode(appKey, "StartTask", "", nil, requestID, 0)); err != nil {
		return "", err
	}
	_, data, err := conn.ReadMessage()
	if err != nil {
		return "", err
	}
	if msg := decode(data); textOf(msg, 4) != "TaskStarted" {
		return "", fmt.Errorf("StartTask 失败: %s %d %s", textOf(msg, 4), codeOf(msg), textOf(msg, 6))
	}

	// ② StartSession
	sessionPayload, _ := json.Marshal(map[string]any{
		"audio_info":              map[string]any{"channel": 1, "format": "raw", "sample_rate": sampleRate},
		"enable_punctuation":      true,
		"enable_speech_rejection": false,
		"extra": map[string]any{
			"did": deviceID, "input_mode": "tool",
			"strong_ddc": true, "use_twopass_retry": true,
			"enable_asr_twopass": true, "enable_asr_threepass": true,
			"disable_user_words": false, "cell_compress_rate": 8,
		},
	})
	if err = conn.WriteMessage(websocket.BinaryMessage,
		encode(appKey, "StartSession", string(sessionPayload), nil, requestID, 0)); err != nil {
		return "", err
	}
	if _, data, err = conn.ReadMessage(); err != nil {
		return "", err
	}
	if msg := decode(data); textOf(msg, 4) != "SessionStarted" {
		return "", fmt.Errorf("StartSession 失败: %s %d %s", textOf(msg, 4), codeOf(msg), textOf(msg, 6))
	}

	// ③ 后台收结果，主线程按 20ms 一帧送音频
	text := make(chan string, 1)
	done := make(chan error, 1)
	go func() {
		var last string
		for {
			_, data, err := conn.ReadMessage()
			if err != nil {
				done <- err
				return
			}
			msg := decode(data)
			if raw := textOf(msg, 7); raw != "" {
				var parsed result
				if json.Unmarshal([]byte(raw), &parsed) == nil {
					for _, item := range parsed.Results {
						if item.Text != "" {
							last = item.Text // 累积文本，最后一条即完整结果
						}
					}
				}
			}
			switch textOf(msg, 4) {
			case "SessionFinished", "TaskFinished":
				text <- last
				return
			case "SessionFailed", "TaskFailed":
				done <- fmt.Errorf("识别失败: %d %s", codeOf(msg), textOf(msg, 6))
				return
			}
		}
	}()

	frames := (len(pcm) + frameBytes - 1) / frameBytes
	for i := 0; i < frames; i++ {
		start := i * frameBytes
		end := start + frameBytes
		if end > len(pcm) {
			end = len(pcm)
		}
		state := 3
		if i == 0 {
			state = 1
		} else if i == frames-1 {
			state = 9
		}
		if err = conn.WriteMessage(websocket.BinaryMessage,
			encode("", "TaskRequest", "{}", pcm[start:end], requestID, state)); err != nil {
			return "", err
		}
		time.Sleep(20 * time.Millisecond) // 按实时速度喂
	}

	// ④ FinishSession
	if err = conn.WriteMessage(websocket.BinaryMessage,
		encode(appKey, "FinishSession", "", nil, requestID, 0)); err != nil {
		return "", err
	}
	select {
	case out := <-text:
		return out, nil
	case err := <-done:
		return "", err
	case <-time.After(25 * time.Second):
		return "", errors.New("等待结果超时")
	}
}

func retryable(err error) bool {
	msg := err.Error()
	return strings.Contains(msg, "service discovery") || strings.Contains(msg, "失败: 5")
}

func transcribe(path string) (string, error) {
	var lastErr error
	for attempt := 0; attempt < maxRetry; attempt++ {
		out, err := transcribeOnce(path)
		if err == nil {
			return out, nil
		}
		lastErr = err
		if !retryable(err) {
			return "", err
		}
		fmt.Fprintf(os.Stderr, "  [重试 %d/%d] %v\n", attempt+1, maxRetry-1, err)
		time.Sleep(600 * time.Millisecond)
	}
	return "", lastErr
}

func main() {
	if len(os.Args) < 2 {
		fmt.Fprintln(os.Stderr, "用法: go run asr_min.go <16k-mono-16bit.wav>")
		os.Exit(1)
	}
	out, err := transcribe(os.Args[1])
	if err != nil {
		fmt.Fprintln(os.Stderr, "失败:", err)
		os.Exit(2)
	}
	fmt.Println(out)
}
三份代码的共同骨架（照这个顺序写就不会错）： ① 注册设备 → ② 换 app_key → ③ 连 WS（带 proto-version: v2）→ ④ StartTask → ⑤ StartSession → ⑥ 循环发 20ms 帧（首帧 1 / 中间 3 / 末帧 9）→ ⑦ FinishSession → ⑧ 读到最后一条累积文本。

4. 集成到你的项目

4.1 网页端为什么要中转

上游需要 3 个无法从浏览器发出的东西：自定义 WS 请求头（proto-version 等）、 设备级 app_key（不能下发到前端）、以及 HTTP 注册请求。所以浏览器方案必须是：

浏览器 ──(16k PCM / WebSocket)──▶ 你的服务端 ──(protobuf / WebSocket)──▶ 字节识别服务 ↑ 录音、去噪、重采样、实时上屏 ↑ 管凭据、帧序号、重试、降级

本 Demo 就是这么做的：前端只管录音和显示，服务端负责凭据、分帧、重试、降级、纠正词典。

// 适合「把一批录音文件转成文字」：连本 Demo 的 /ws，喂 PCM，收最终文本
import fs from "node:fs";
import WebSocket from "ws";

async function transcribeFile(path) {
  const pcm = readWav16kMono(path);                       // 见 examples/asr_min.js 的 readWav
  const ws = new WebSocket("wss://<你的域名>/ws?engine=auto");
  return new Promise((resolve, reject) => {
    let done = null;
    ws.on("open", async () => {
      for (let i = 0; i < pcm.length; i += 640) {
        ws.send(pcm.subarray(i, i + 640));
        await new Promise((r) => setTimeout(r, 20));      // 按实时速度喂（也可更快）
      }
      ws.send(JSON.stringify({ type: "stop" }));
    });
    ws.on("message", (raw) => {
      const msg = JSON.parse(raw);
      if (msg.type === "final") { done = msg; resolve(msg.text); ws.close(); }
      if (msg.type === "error") reject(new Error(msg.message));
    });
    ws.on("close", () => { if (!done) reject(new Error("连接提前关闭")); });
  });
}

4.3 生产环境注意事项

点建议
凭据缓存device_id + app_key 落盘复用（600 权限），别每次请求都重新注册
重试50700000 是随机抖动（约 1/5），整段重试 3~4 次；40200011 不要重试（配额满）
并发所有客户端共享同一个 app_key 的配额，服务端做信号量（本 Demo 默认 3 路）
帧节奏按实时速度喂即可（20 ms/帧 = 32 KB/s）；一次性灌太快容易触发异常
末帧实时流不知道哪帧是最后一帧 → 压一帧，收尾时把压着的这帧标 9 再发 FinishSession
安全不要在前端暴露 app_key；服务端加鉴权（本 Demo 用 API key / 访问控制即可）
合规这是未公开的内部接口，接口可能变更、风控可能封禁；正式产品请用官方接口（见下节）

5. 说话人分离（可选）

上游 ASR 的结果里没有 speaker 字段，所以「谁说的」得我们自己算。 默认走 online 模式：每句一定稿就提一次声纹、和已有说话人比相似度，边录边出标签； 也可以设 DOUBAO_DIAR_MODE=batch 改成"录完整段再聚类"（更准、但要等）。

录音（16k PCM） ├─ 分割：pyannote segmentation-3.0（ONNX，6 MB）→ 逐帧说话人活动 ├─ 声纹：3D-Speaker ERes2Net（ONNX，38 MB）→ 每段的说话人向量 ├─ 聚类：余弦相似度 + 阈值（默认 0.7）→ 谁和谁是同一个人 └─ 对齐：拿每句的 [start,end] 和分离片段求最大重叠 → spk 标签

这套配方与 screenpipe 一致（它的 Rust 实现同样是 pyannote 分割 + 3D-Speaker 类声纹 + 自定义聚类）； 本项目直接用 sherpa-onnx 的现成实现，省掉自己接 ONNX。

单人录音只有 1 人，不会硬拆

声纹库：从"1 号 2 号"升级到"这是谁"

分离只给出匿名编号，而且编号只在单次录音内有意义。想跨录音认人，就把说话人的声纹存下来做 1:N 识别： 有两种方式：① 打开 /voice 声纹管理页，念 3 段不同内容（每段 2~4 秒）， 页面会显示每段的质量和"与前几段的一致性"，保存即入库（推荐，最干净）； ② 在录音页点「说话人 N」标签、填真名并确认"记住这个声音"。 入库的是那个人每段录音的声纹向量（CAM++，192 维），存在浏览器 localStorage； 每次会话开始时随 config 发给服务端，新句子先跟声纹库比余弦（默认阈值 0.5）， 认得就用真名（页面显示 ✓ 姓名），认不出再走会话内聚类。一个人可存多例， 检索取"最像的那一例"。

实测：在声纹管理页录 2 段注册「小飞」→ 回录音页边说边显示 ✓ 小飞； 同一段里没注册的英文男声保持「说话人 2」——不会把陌生人硬塞成已注册的名字。
声纹模型怎么挑（实测 2 人 × 3 段）： ERes2Net-zh（38MB，中文专用）同人最低相似度 +0.29、异人最高 −0.02，可分性只有 0.31； 换成 CAM++ zh_en（28MB，中英双语）后同人 ≥ +0.72、异人 ≤ +0.05，可分性 0.67， 阈值 0.5 很安全。多例注册还有额外增益：1 秒短句 1 例 9/10 正确 → 4 例 4/4（A-B 分差 0.54 → 0.63）。
局限：不做重叠语音（两人同时说话归给其中一人）；在线追踪是逐句独立判断， 说话人编号只在这一次录音内有意义（跨录音不会自动认人，要认人得自己建声纹库）； 太短的句子（<0.6s）算不出可靠声纹，会继承上一位说话人。

6. 离线 / 本地方案

本项目自带离线引擎（offline_engine.py）：用的是字节公开分发的 ASR 模型 （见 1.7），纯 ONNX + onnxruntime，不联网、不依赖豆包客户端。 网页上可以三档切换，方便对比效果：

档位走哪条路特点
自动（默认）engine=auto：云端优先，握手失败/会话中断/重连失败 → 自动切离线引擎（再不行才用 FunASR）日常用
在线engine=cloud：只用豆包云端最准、带标点、有热词上下文
离线engine=offline：只用本机 ONNX 模型断网可用、有真实句级时间戳与质量分；英文弱一些

每次会话的分隔线上会标出用了哪档（如 2026-10-17 03:33 · 离线 · 录音 43s / 识别到 42s），方便回溯对比。

7. 常见问题

Q：为什么我自己连不上，一直 50700000？

上游随机抖动（实测约 1/5），重试整段即可。如果重试也一直失败，可能是接口变了或被风控，换新设备试试、或改用本地引擎。

Q：直接用 whisper-1 模型名行不行？

不行，这不是 OpenAI 接口。字段 5 是固定的方法名，音频字段是裸 PCM/Opus，不解析 multipart。

Q：能不能不注册设备、硬编码一个 app_key？

不建议：app_key 按设备下发且会轮换，硬编码很快就失效；而且那属于拿别人的凭据。

Q：识别结果能拿到逐字时间吗？

能，在 results[].alternatives[].words[] 里（注意 end_time 偏大，需要按 1.3 的坑校正）。

Q：能做成 OpenAI 兼容的 /v1/audio/transcriptions 吗？

能，服务端包一层即可：接收 multipart → 转 16k PCM → 走本节协议 → 返回 {"text": ...}。 本 Demo 目前只提供了 WebSocket 接口，需要 HTTP 版可以照着 4.2 的协议自己加。
